# 🎮 Whack-a-Mole Game

A fun, interactive Whack-a-Mole game built with HTML, CSS, and JavaScript.

## Features

✅ **Game Board**: 3x3 grid of holes where moles randomly appear  
✅ **Random Mole Generation**: Moles pop up at random intervals  
✅ **Scoring System**: Earn points for each mole you whack  
✅ **Game Timer**: 30-second game sessions  
✅ **Visual Feedback**: Animations when moles are hit  
✅ **Responsive Design**: Works on different screen sizes  

## How to Play

1. Open `index.html` in your web browser
2. Click the "Start Game" button to begin
3. Click on moles as they pop up from holes
4. Each successful hit increases your score by 1
5. Try to get the highest score before time runs out!
6. Click "Reset" to restart or "Play Again" after game over

## Game Controls

- **Start Game**: Begin a new game session
- **Reset**: Reset the game at any time
- **Play Again**: Restart after game over

## Game Settings

You can modify these settings in `script.js`:

- `GAME_DURATION`: Game length in seconds (default: 30)
- `MOLE_SHOW_TIME`: How long moles stay visible in milliseconds (default: 1000)
- `MOLE_SPAWN_INTERVAL`: Time between mole spawns in milliseconds (default: 800)

## Files

- `index.html` - Main game structure
- `style.css` - Game styling and animations
- `script.js` - Game logic and functionality

## Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript (no frameworks required)

Enjoy the game! 🎯
